# Speedometer Hobby App

A simple Android app inspired by the speedometer gauge style in the Midash dashboard concept.

This project was created as a hobby project using AI assistance. It is not a professional app and it has not been tested in a production environment. It is intended only as a personal learning project and a place to store experimental code fragments.

Please note:
- This repository is not a professional development project.
- The code may contain bugs, rough edges, or incomplete parts.
- Files in this repository may be experimental and can change without notice.
- This project is mainly for personal exploration, creativity, and saving small UI experiments.

## Features
- Neon cyan dashboard gauge
- Speed display like a car instrument cluster
- Speed limit badge
- Gear indicator row
- Easy to customize

## Run this project
1. Open in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or device.
