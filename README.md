# Speedometer Hobby App

A simple Android app inspired by the speedometer gauge style in the Midash dashboard concept.

This project was created as a hobby project using AI assistance. It is not a professional app, but it is a working Android UI prototype.

## Features
- Neon cyan dashboard gauge
- Speed display like a car instrument cluster
- Speed limit badge
- Gear indicator row
- Easy to customize

## Run this project
1. Open in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or device.

## Notes
This app is intentionally simple and designed for learning and creativity.
